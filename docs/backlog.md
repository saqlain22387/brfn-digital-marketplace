# Product Backlog

| ID | User Story | Actor | MoSCoW | Points | Sprint |
|----|-----------|-------|--------|--------|--------|
| US-01 | As a Producer, I want to submit a product listing with all required details so that it can be published on the marketplace | Producer | Must | 8 | S2 |
| US-02 | As the Marketplace, I want to validate mandatory fields on submission so that incomplete listings are rejected before publication | Marketplace | Must | 3 | S2 |
| US-03 | As a Producer, I want to be shown which fields are invalid so that I can correct my submission | Producer | Must | 3 | S2 |
| US-04 | As the Marketplace, I want to verify organic certification via an external verification service so that false organic claims are blocked | Marketplace | Must | 5 | S2 |
| US-05 | As the Marketplace, I want to handle verification service unavailability gracefully so that listings are not lost when the service is down | Marketplace | Must | 3 | S2 |
| US-06 | As a Producer, I want to update product quantity so that stock levels stay accurate | Producer | Must | 3 | S2 |
| US-07 | As a Producer, I want to update seasonal availability so that products only appear when in season | Producer | Should | 3 | S2 |
| US-08 | As the Marketplace, I want to automatically mark products unavailable when stock reaches zero so that customers cannot order out-of-stock items | Marketplace | Must | 3 | S2 |
| US-09 | As the Marketplace, I want to automatically re-enable products when restocked within season so that producers can resume selling | Marketplace | Should | 2 | S3 |
| US-10 | As a Customer, I want to browse and search products so that I can find what I want to buy | Customer | Must | 5 | S2 |
| US-11 | As a Customer, I want to add products from multiple producers to one basket so that I can order from several vendors at once | Customer | Must | 5 | S2 |
| US-12 | As the Marketplace, I want to check stock availability at checkout so that unavailable items are caught before payment | Marketplace | Must | 5 | S2 |
| US-13 | As a Customer, I want to be informed of unavailable items so that I can amend my order | Customer | Must | 3 | S2 |
| US-14 | As the Marketplace, I want to determine delivery or collection arrangements per producer so that the customer knows how each item arrives | Marketplace | Should | 5 | S2 |
| US-15 | As the Marketplace, I want to split a multi-vendor order into producer-specific orders so that each producer fulfils their own items | Marketplace | Must | 8 | S2 |
| US-16 | As a Customer, I want to pay via the payment service so that I can complete my purchase | Customer | Must | 5 | S2 |
| US-17 | As the Marketplace, I want to calculate each producer's amount and the 5% commission so that payments are distributed correctly | Marketplace | Must | 5 | S2 |
| US-18 | As a Customer, I want to retry payment if it is declined so that I can still complete my order | Customer | Must | 3 | S2 |
| US-19 | As the Marketplace, I want to handle payment service unavailability with a retry path so that orders are not lost | Marketplace | Must | 3 | S2 |
| US-20 | As a Producer, I want to be notified when an order is confirmed so that I can prepare it | Producer | Should | 2 | S3 |
